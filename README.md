# Check-In Tracker

A Progressive Web App for tracking daily activities with timestamped check-ins. Built with vanilla JavaScript and Vite.

## Features

- Quick check-in buttons for common activities
- Custom activity tracking
- 7-day history view
- Offline support (PWA)
- Installable on mobile and desktop
- Dark mode interface

## Live Demo

The app is deployed to Pages and available at:

**https://task-logger.lightroasted.vps-kinghost.net**

## Development

Install dependencies:
```bash
npm install
```

Run development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```

## Tech Stack

- Vite - Build tool
- vite-plugin-pwa - PWA support
- Vanilla JavaScript (ES6+)
- CSS (iOS-inspired design)
